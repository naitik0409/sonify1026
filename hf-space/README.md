# Sonify 1026 - voice demo

Interactive demo for the **Sonify 1026** voice engine: an expressive, adaptive
Indian female TTS voice that reads Indian English and code-switches into Hindi,
shaping pitch, rate, volume, brightness, warmth and pauses to the meaning of
each sentence.

Type English, Hindi or Hinglish, choose an emotion, press **Speak**.

- Package: https://pypi.org/project/sonify1026/ (`pip install snfy`)
- Source: https://github.com/naitik0409/sonify1026
- Built by **Naitik** - MIT licensed.

Audio is served by Microsoft Edge TTS, so this Space needs outbound internet.
